A simple static site

This site is generated from React components and saved as plain HTML and CSS. It does not need React or Next.js to run.

What is included

Five linked pages share one stylesheet and a responsive layout.

  • A home page with a short introduction
  • About, services, projects, and contact pages
  • One shared CSS file for every page

How it is built

React components are rendered to static markup ahead of time. The result is ordinary HTML that can be hosted anywhere.

Where to go next

Use the navigation above to visit each page. The site also works when opened directly from disk.
